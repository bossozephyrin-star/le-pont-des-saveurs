## Transformations et réutilisation

Toutes les photos ont été redimensionnées à 800 px de large et converties en WebP, qualité 75, avec Pillow/libwebp. La photo d’alloco a été recadrée pour montrer les bananes plantains frites et leur sauce. Les versions transformées sont distribuées sous la même licence que leur source, indiquée dans le tableau. Le crédit de Gunsaram conserve l’attribution du recadrage déjà présent sur Commons pour le mafé.

Les téléchargements des originaux ayant reçu une réponse HTTP 429, les versions réduites proposées par l’API Commons ont été utilisées : 960 px pour six photos et 1920 px avant recadrage pour l’alloco. Aucune image n’a été agrandie.

Les sept fichiers totalisent **315 952 octets**. Ils sont chargés à la demande avec `loading="lazy"`. Les attributs HTML `width` et `height` correspondent aux dimensions des fichiers, et chaque image possède un texte alternatif descriptif.

L’attiéké poisson braisé et le saka-saka restent sans image : aucun cliché suffisamment adapté n’a été retenu lors de cette sélection. Le saka-saka présent en accompagnement sur la photo du poulet moambé est décrit dans son texte alternatif, sans être réutilisé comme photo du plat de saka-saka accompagné de chikwangue.

La photo d’ambiance Pexels conserve ses crédits distincts dans le README et le pied de page.
